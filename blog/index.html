On building a quieter web presence

WEB DESIGN NOTES

A personal site does not need to behave like a product. It needs to load fast, say the important things clearly, and leave room for writing that ages well. That is the direction here.

The current visual language treats the page like a printed record: hard borders, monochrome contrast, editorial spacing, and very little chrome that does not earn its place. A blog in this system should feel like an extension of the same document, not a separate app.

The point is not to look retro. The point is to make the page feel deliberate.

Real posts can eventually cover research process, reinforcement learning experiments, paper summaries, and occasional technical notes. For now, this page exists to prove the style can carry longer writing without losing coherence.
